The conventions being followed

One object, many sizes

The island never appears or disappears — it grows and shrinks. Windows that pop in read as interruptions; a morph reads as the same thing paying attention.

Ask at the moment of purpose

No permission is requested before the screen that shows why it exists. A batch of prompts on launch is the single most common way trust is lost.

Never block on an account

Capture, clipboard and export work signed out, forever. The account row buys the rewrite, not the tool.

State, not instructions

Permission rows show what is true now and change in place. Telling someone to visit System Settings is what a UI does when it cannot see its own state.

Silence is the default

Nothing speaks during a pass. Confirmation is a shape change and a count — legible in peripheral vision, ignorable, and impossible to talk over.

The pass is uninterruptible

No question, no confirmation, no error can appear while the chord is held. Anything that needs attention waits for the release.
